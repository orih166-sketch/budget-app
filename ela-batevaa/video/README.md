# סרטון הדרכה – אלה בטבע

סרטון הדרכה אנכי (1080×1920) שמציג את כל השלבים והפעולות במערכת, בסגנון של סרטון ההדרכה של צוות המדריכים.

המבנה:
- פתיחה
- 4 חלקים: מסך הבית, מכירה וקבלה, פולואפים ולקוחות, כספים מלאי ומועדון
- סיכום "מה לזכור"

הסרטון בנוי ממסכים אמיתיים של המערכת עם נתוני דוגמה, עם סמן שמראה על מה לוחצים וכותרת לכל שלב.

## יצירה מחדש

```bash
node ../scripts/build.mjs   # בונה את גרסת ההדגמה של המערכת
npm install
node capture.js             # מצלם את כל השלבים מתוך המערכת -> shots/
node render.js              # מרנדר -> out/ela-batevaa-guide.mp4
node render.js --preview 5 30   # רק תמונות סטילס בשניות מסוימות
```

דרישות: Node 18+, Playwright עם Chromium, ffmpeg, pdftoppm ו־Python 3 עם numpy.

## קבצים

- `capture.js`: התסריט. כל קריאה ל־`step()` היא שלב בסרטון, עם כותרת ועם מה לוחצים.
- `video.html`: העיצוב והאנימציה. הקובץ דטרמיניסטי: `renderAt(t)` מצייר את הפריים בזמן t.
- `render.js`: מצלם כל פריים ומקודד ל־MP4.
- `sfx.py`: אפקטי הסאונד (קליקים ומעברים).
