# אלה בטבע – מערכת ניהול העסק

מערכת אישית לניהול העסק של אלה (מוצרי טיפוח ובריאות של פוראבר): לקוחות ולידים, מכירות וקבלות לעוסק פטור, הכנסות והוצאות, מלאי, פולואפים אוטומטיים, הודעות וואטסאפ מהירות ומועדון לקוחות.

המערכת רצה כ־**Google Apps Script Web App** בחשבון Google של אלה:
- **כניסה עם Google** – רק החשבון `elah262@gmail.com` יכול לפתוח אותה.
- **הנתונים** נשמרים בגיליון Google חדש בחשבון שלה: ״אלה בטבע – מערכת ניהול (לא למחוק)״.
- **הקבלות** נשמרות כקובצי PDF בתיקייה ״אלה בטבע – קבלות״ ב־Drive, לפי שנים.
- אין עלות, אין שרת ואין צורך בהתקנה. עובד מהטלפון ומהמחשב.

## מה יש במערכת

| מסך | מה עושים בו |
|---|---|
| **בית** | סיכום החודש, ניצול תקרת עוסק פטור, פולואפים להיום, מלאי נמוך, לידים פתוחים ולקוחות לשימור |
| **מכירה חדשה** (הכפתור הירוק) | בוחרים לקוח ומוצרים מהמלאי ← קבלה ממוספרת ב־PDF עם הלוגו ← שליחה בוואטסאפ. המלאי יורד אוטומטית ונקבעים 2 פולואפים: אחרי 3 ימים (״התחלת להשתמש? זה עוזר?״) ואחרי חודש (״רוצה לחדש?״) |
| **פולואפים** | רשימת משימות לפי תאריך. כפתור וואטסאפ פותח הודעה מוכנה עם שם הלקוח והמוצר. ״בוצע״ / ״דחייה״ |
| **לקוחות ולידים** | ליד חדש מוואטסאפ בשתי שניות, שלבי ליד, כרטיס לקוח עם היסטוריית רכישות, סימון חברי מועדון, לקוחות שלא קנו 60 יום |
| **הכנסות והוצאות** | תצוגה שנתית וחודשית, גרף, הוצאות לפי קטגוריה, ביטול קבלה (נשארת בתיעוד), ייצוא CSV לרואה החשבון |
| **מלאי מוצרים** | כמות בבית, התראה על מלאי נמוך, קליטת משלוח מפוראבר (מעדכן מלאי ורושם הוצאה), ייבוא מקובץ Excel, העתקת רשימת חוסרים |
| **מועדון לקוחות** | תבניות מוכנות לפוסטים (מוצר חדש, טיפ, הטבה, המלצה), תכנון לפי תאריכים, שליחה לקבוצת הוואטסאפ, הזמנת לקוחות למועדון |
| **הודעות מהירות** | נוסחים קבועים עם `{שם}`, `{מוצרים}`, `{קבלה}` – עריכה והוספה חופשית |
| **הגדרות** | פרטי העסק בקבלה, מספר הקבלה הבאה, ימי הפולואפ, תקרת עוסק פטור, קישור לקבוצת המועדון |

## התקנה (פעם אחת, כ־10 דקות)

> חשוב: כל השלבים נעשים **כשמחוברים לחשבון `elah262@gmail.com`**, כדי שהנתונים והקבלות יישמרו אצלה.

### אפשרות א׳ – העתקה ידנית (בלי כלים)

1. נכנסים ל־[script.google.com](https://script.google.com) ← **פרויקט חדש**. משנים את השם ל״אלה בטבע״.
2. **הגדרות הפרויקט** (גלגל השיניים בצד) ← מסמנים ״הצגת קובץ המניפסט appsscript.json בעורך״.
3. חוזרים ל**עורך** ומעתיקים את הקבצים מתיקיית `src`:
   - `Code.gs` – מחליפים את כל התוכן של `Code.gs` הקיים.
   - `appsscript.json` – מחליפים את התוכן.
   - יוצרים 4 קובצי HTML (כפתור ➕ ← HTML) בשמות **בדיוק** כך, בלי הסיומת: `Index`, `Styles`, `App`, `Logo`. מדביקים בכל אחד את התוכן של הקובץ התואם.
4. שומרים, בוחרים בפונקציה `setup` בסרגל העליון ולוחצים **הפעלה**. Google תבקש הרשאות (גיליונות ו־Drive). מאשרים: ״מתקדם״ ← ״מעבר לאלה בטבע״ ← ״אישור״.
5. **פריסה** ← **פריסה חדשה** ← סוג: **אפליקציית אינטרנט**:
   - הפעלה בתור: **אני**
   - למי יש גישה: **רק אני**
   - לוחצים **פריסה** ומעתיקים את הקישור.
6. פותחים את הקישור בטלפון ← בתפריט הדפדפן: **הוספה למסך הבית**. מעכשיו זה נראה כמו אפליקציה.

### אפשרות ב׳ – עם clasp (למי שמכיר טרמינל)

```bash
npm i -g @google/clasp
clasp login                      # להתחבר עם elah262@gmail.com
cd ela-batevaa
clasp create --type standalone --title "אלה בטבע" --rootDir src
clasp push
clasp open                        # ואז שלבים 4–6 מלמעלה
```

### עדכון גרסה בעתיד

אחרי שינוי בקוד: **פריסה** ← **ניהול פריסות** ← עריכה (✏️) ← גרסה: **גרסה חדשה** ← פריסה. הקישור נשאר אותו קישור.

## דברים שכדאי לדעת

- **מספור קבלות:** ברירת המחדל מתחילה ב־`0001`. אפשר לשנות בהגדרות ← ״מספר הקבלה הבאה״, אבל רק כלפי מעלה. אין אפשרות למחוק קבלה, רק לבטל אותה. הקבלה המבוטלת נשארת בתיעוד ומסומנת ״מבוטלת״.
- **תקרת עוסק פטור:** מוגדרת ל־120,000 ₪. מומלץ לבדוק מול רואה החשבון את התקרה המעודכנת לשנה הנוכחית ולעדכן בהגדרות.
- **וואטסאפ:** הכפתורים פותחים את וואטסאפ עם ההודעה מוכנה, ואת השליחה עצמה עושים בלחיצה. לקבוצת המועדון: ״שליחה לקבוצה״ פותח את וואטסאפ עם הטקסט, ושם בוחרים את הקבוצה.
- **ייבוא המלאי הקיים:** מלאי ← ״ייבוא מקובץ״ ← בוחרים את קובץ ה־Excel. המערכת מזהה לבד את העמודות (שם, קוד, כמות, מחיר) ואפשר לתקן לפני הייבוא.
- **גיבוי:** כל הנתונים נמצאים בגיליון Google רגיל בחשבון של אלה. אפשר לפתוח אותו מההגדרות. לא לשנות שם של לשוניות או את סדר העמודות.

## למפתחים

```
src/            קבצי Apps Script (זה מה שעולה ל-Google)
  Code.gs       צד שרת: אחסון בגיליון, קבלות, מלאי, פולואפים
  Index.html    שלד הדף
  Styles.html   עיצוב
  App.html      כל הממשק (JS ללא תלויות; html2canvas/jsPDF/SheetJS נטענים מ-cdnjs לפי הצורך)
  Logo.html     הלוגו המוטמע (נוצר ע״י build)
assets/         הלוגו המקורי
preview/        גרסת הדגמה שרצה מקומית עם נתוני דוגמה (mock.js במקום השרת)
scripts/build.mjs   בונה את Logo.html ואת preview/index.html
```

`node scripts/build.mjs`, ואז לפתוח את `preview/index.html` בדפדפן לצפייה בהדגמה עם נתונים פיקטיביים.
